# Bayan · بيان

Static site: `index.html` + `img/`. No build step.
Vercel: Framework Preset = Other, Build Command empty, Output Directory `.`

Bayan shares its app with Memory of a Nation (ذاكرة وطن). It is built from that
project's `index.html` by swapping the brand layer: name, book wordmark, Cairo
for Arabic, navy and gold palette with a blue accent, Bayan's backgrounds and
icons, English as the default language, and the full library (the classics plus
the 20 King Fahd National Library books).
