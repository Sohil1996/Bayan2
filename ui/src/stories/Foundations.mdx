# Tokens

All tokens are CSS variables (`--by-*`) defined in `src/styles/theme.css`, with a dark set on `:root` and a light set on `[data-theme='light']`.
Tailwind utilities point at them, so `bg-gold` or `text-fg-muted` change with the theme automatically.
The swatches below follow the **Theme** toolbar.

## Colours

In dark mode the primary action is gold with dark text; in light mode it is navy with white text.
Use `gold-ink`, not `gold`, for gold text on the page background: it passes WCAG AA contrast in both themes.

## Surfaces

## Type

Latin text uses **Inter** for the interface and **Canela** for display (falling back to Cormorant Garamond if you don't hold a Canela licence).
Arabic uses **Cairo** for everything. The switch happens automatically on `dir="rtl"` or `lang="ar"`.

## Sizes

| Token | Value | Use |
|---|---|---|
| `h-chip` | 30px | Chips, header icon buttons |
| `h-control` | 44px | Buttons, tabs: the minimum touch target |
| `h-field` | 50px | Form fields |
| `min-h-composer` | 56px | Chat composer |
